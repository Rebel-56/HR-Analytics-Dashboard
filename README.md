# 👥 HR Analytics Dashboard

An HR analytics project that analyses employee data to understand **workforce composition and employee attrition**. It calculates key HR KPIs, finds the factors linked to attrition, and presents everything as a dashboard in three ways:

1. **Static HTML dashboard** (`outputs/hr_dashboard.html`) – KPI cards, auto-generated insights and six charts. Open it in any browser, no setup needed.
2. **Interactive Streamlit app** (`app.py`) – the same KPIs and charts with sidebar filters for department, gender and overtime.
3. **Power BI guide** (`powerbi/powerbi_guide.md`) – DAX measures and a page layout to rebuild the dashboard in Power BI.

> **Note on data:** the included dataset (`data/hr_data_sample.csv`) is **synthetic**, generated by `data/generate_hr_data.py` so the project runs out of the box. The findings below describe this sample, not a real company. See [Using real data](#using-real-data) to analyse a real dataset.

## KPIs tracked
Headcount · Attrition rate · Employees who left · Average monthly income · Average tenure · Average job satisfaction · Overtime rate

## Findings (on the synthetic sample)
- Overall attrition is **17.1%** (257 of 1,500 employees).
- Employees working **overtime leave at 26.1%** versus 13.6% for those who don't (1.9x higher).
- Employees with **low job satisfaction (1-2)** leave at 23.3% versus 13.9% for satisfied employees (3-4).
- **New joiners (0-1 years)** leave at 22.0%, compared with 13.8% for employees with 10+ years.
- Differences between departments are small (14.5% to 19.2%), so department alone is a weak signal here.

The overtime, satisfaction and tenure patterns appear because the sample data was generated with those relationships built in. On real data, treat them as hypotheses to test rather than conclusions.

## Using real data
A well-known public option is the **IBM HR Analytics Employee Attrition & Performance** dataset on Kaggle. To use your own file, make sure it has columns with these names (rename them if needed):

`Department, JobRole, Gender, Age, MonthlyIncome, YearsAtCompany, OverTime, JobSatisfaction, Attrition`

then run:
```bash
python src/build_report.py --data path/to/your.csv
```
Attrition must be `Yes`/`No` and OverTime `Yes`/`No`. The Streamlit app reads `data/hr_data_sample.csv`; replace that file (or change `DEFAULT_DATA` in `src/kpis.py`) to point it at your data. I did not test against the IBM file, so check the column names and values first. Its income is in US dollars, so the "INR" labels in the charts would need changing.
